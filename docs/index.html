Prefer the real thing? Run it in one command.

The playground above is a faithful client-side simulation. The actual RateGate server is a multi-arch distroless container on GHCR — pull it and you have a live gRPC + REST rate limiter in seconds.

1

Run the server

Non-root distroless image, ~25 MB, linux/amd64 + arm64.

docker run -d --name rategate \ -p 8080:8080 -p 9090:9090 \ ghcr.io/abolfazlrwm/rategate:v0.2.1
2

Check a request

REST on :8080 (gRPC on the same port). Mirrors the playground policy.

curl -sX POST localhost:8080/v1/check \ -H "content-type: application/json" \ -d '{"key":"user:42","algorithm":"tokenbucket", "limit":10,"refill_per_second":2}'

See the API reference for the full gRPC service, adaptive config, and Prometheus / OpenTelemetry endpoints.
